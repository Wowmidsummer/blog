欢迎来到我的博客!

这个博客使用 [Hugo](https://gohugo.io) 搭建,主题是 [PaperMod](https://github.com/adityatelange/hugo-PaperMod),部署在 GitHub Pages 上,完全免费。

## 如何写新文章

在 `content/posts/` 目录下新建 Markdown 文件即可:

```bash
hugo new content posts/文章标题.md
```

把文件头部的 `draft = true` 改成 `false`,写正文,然后推送到 GitHub,文章就会自动发布。

## 本地预览

```bash
hugo server -D
```

浏览器打开 http://localhost:1313 就能实时预览。
